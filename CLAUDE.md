# home-lab — quick map

Dense index so you can jump straight to files. Conventions and rationale
live in `.claude/CLAUDE.md`. The README is the human-facing guide.

## Stack (verified against package.json)

React **19** · TypeScript **5.9** · Vite **6** · SWR **2** · plain CSS ·
Node server on `node:http` (no framework) · Vitest **3** + jsdom ·
Playwright **1.63** (desktop + Pixel 7 + iPad Pro 11 landscape) · Node **20.12+**.

## Commands

- Dev: `npm run dev` → http://localhost:5180 (API mounted into Vite)
- Prod: `npm run build && npm start` → http://127.0.0.1:4180
- Preview build with no server: `npm run build:preview` → `dist-preview/`
- `npm run typecheck` · `npm run test:unit` · `npm run test:e2e` · `npm test`

## Where things are

- **API:** `server/app.mjs` — `GET /api/snapshot`, `POST /api/actions/:name`
  (`ollama-unload`, `ollama-load`; needs header `x-home-lab: 1`; one at a time, 409 otherwise),
  `POST /api/jarvis/ask` (`{text}`, same header; forwards `Tailscale-User-Login` to Jarvis `/ask`),
  `POST /api/jarvis/chat` (`{text, images?}`, same header; `images` = up to 4 photos `{media_type, data}` base64 for the apps' chat, `parseChatImages`, history turns carry `images: n` and Jarvis's `id`; a turn whose `model` is `notice:<source>` is a message he sent unasked (reminder, Lookout, start of day), and its `writer` is the model that wrote it; `chipFor` in `src/lib/model.ts` shows the writer's usual chip then the source word in grey, "Jarvis (CO) Lookout", or plain "Jarvis" + the word when no model wrote it; a `meal_question` event (`key`, `choices`) is answered with `POST /api/jarvis/chat/meal` `{key, choice: same|leftovers|new}` → Jarvis `/chat/meal`; streams Jarvis `/chat/stream` NDJSON; if the phone drops it, the server reads on and the page catches up from history via `src/lib/chatCatchUp.ts`), `GET /api/jarvis/history` (Jarvis `/chat/history`), `POST /api/jarvis/warm` (same header; Jarvis `/chat/warm`, sent when the chat sheet opens),
  `POST /api/jarvis/sleep` (`{asleep, source?}`, same header + Tailscale login; Jarvis `/sleep`; the Apple TV's Night button says you've gone to bed, Jarvis marks you up again when you next talk to him),
  `POST /api/jarvis/approve` (`{id, ok}`, same header; Jarvis `/approve`; 410 `{ok: false, gone: true, message, answer?: {ok, by, later}}` when that request is already over, so every screen drops its card for good) + `GET /api/jarvis/approvals` (Jarvis `/approvals`): Approve/Deny cards for `approval`/`approval_done` events on the chat stream and talk line (`ApprovalCard` in `JarvisPanel`; typing dots `TypingDots` while he thinks, looks something up, or goes quiet 1.5 s mid-reply; labels + outcome text in `src/lib/approvals.ts`; `later: true` = he said "wait"; once answered, or when `expires` passes with no answer, the card shrinks to one history line via `settledLine` ("Approved: …", "Timed out: …"); self-change tools `change_code`/`apply_code_change`/`change_setting`),
  `POST /api/jarvis/feedback` (`{question, answer, note}`, same header + Tailscale login; Jarvis `/feedback`; a faint "…" ("That was wrong") at the end of each finished reply in chat and on /talk opens the `WrongDialog` pop-up (`WrongButton` in `JarvisPanel`); Jarvis turns flags into a fix + eval case overnight),
  `POST /api/jarvis/offers/hide` (`{id}`, same header; Jarvis `/offers/{id}/hide`) + snapshot `offers` (Jarvis `GET /offers`, `server/sources/offers.mjs`): greeting under the Overview title, `OfferCards` (Hide/Start) under the Ask bar; Start = chat with `offerId`,
  `POST /api/jarvis/notices/clear` (`{ids}` or `{all: true}`, same header; Jarvis `/notices/clear`) + snapshot `notices` (Jarvis `GET /notices`, `server/sources/notices.mjs`: unread notifications `{id, kind: need|heads|fyi, title, body, source, created, approvalId?, turnId?}` (`turnId` = the history turn `id` holding the full message, so a tap opens the chat there; `kept: true` once he chose to keep it, with `source: kept` for a kept chat message); `POST /api/jarvis/notices/keep` (`{turnId}` = a chat message or `{id}` = a notice, same header; Jarvis `/notices/keep` with `turn_id`/`notice_id`; answers `{ok, message, notice?}`) + `POST /api/jarvis/notices/unkeep` (`{id}`; Jarvis `/notices/unkeep`): a kept one is a yellow dot in the apps and stays through Clear and Clear all until he lets it go, and its history turn carries `kept: true` (Dylan 2026-11-19; `parseKeep`/`parseUnkeep`); the apps show one dot on the orb each and one shared list, cleared everywhere at once; no panel on the page yet) + `POST /api/jarvis/push/register` (`{token, platform, environment, bundle, name?}`, same header; Jarvis `/push/register`, so he can send lock-screen pushes to that device),
  `GET /api/jarvis/memory` + `GET /api/jarvis/memory/search?q=` + `POST /api/jarvis/memory` (`{op: remember|forget}`, same header; Jarvis `/memory/facts`, `/memory/search`; `MemoryPanel` = Memory, last on Settings),
  `GET /api/jarvis/playbooks` (`{book: {playbooks, options}}`) + `POST /api/jarvis/playbooks` (`{op: save, playbook}` or `{op: delete|run, id}`, same header + Tailscale login; Jarvis `GET/POST /playbooks`, `/playbooks/{id}/delete`, `/playbooks/{id}/run` (answers `{ok, detail, checks}`, or `detail: running` after 50 s); checks and snake_case mapping in `server/sources/playbooks.mjs`): the **Playbooks** tab, which replaced Routines 2026-11-18 (`src/views/Playbooks.tsx`, editor pop-up `PlaybookEditor`, words in `src/lib/playbooks.ts`, `usePlaybooks`/`changePlaybook` in the client; fetched when the tab opens, not in the snapshot). A playbook = name, on/off, what it's for, one trigger (time + days, arrive, leave, asleep, awake, manual) and up to 20 steps (device, scene, app on a TV, notify, `think` = Jarvis does it in words with `model` auto|worker (Ornith)|claude, email, wait), a **done** checklist Jarvis checks himself against after each run (`lastRun.checks`; failed ones show as "Not done: …" on the row), plus "More for Jarvis" (when to use, inputs, decisions if/then, edge cases, standard, bad version). What the page saves is `made_by: dylan`, which runs without asking (an email step asks only when `confirm` is true); `madeBy: jarvis` = one he proposed,

  `GET`/`POST /api/jarvis/voice` + `GET /api/jarvis/voice/sample` (WAV; checks in `server/voice.mjs`; Jarvis `/voice`, `/voice/sample`; `VoicePanel` on Settings before Memory),

  `POST /api/digest/refresh` (same header; asks Jarvis `/digest/refresh`; client hook `src/api/digestRefresh.tsx`),

- **Calories:** snapshot `nutrition` = Jarvis `GET /nutrition/today` (`server/sources/nutrition.mjs parseNutrition`: `{date, eaten, goal, left, burned, protein, proteinGoal}`, numbers only; feeds the Watch's Calories left complication; no panel on the page).
